Locate the two `<TradeSummaryCard>` instances inside `renderTradeStatusPanel()` at ~lines 1214–1225.

**Root cause:** `estimatedValueZar={yourValue > 0 ? yourValue : null}` and `estimatedValueZar={theirValue > 0 ? theirValue : null}` use pile totals (sum of added trade items). When no items have been added, the pile total is 0 and null is passed — so no ZAR value renders, even though the listing has `estimatedValueZar` set.

**Fix:** For the card side that OWNS the trade listing, pass `listing.estimatedValueZar` directly. For the OTHER side (whose items come from `tradeItems`), keep the pile total fallback.

Replace the YOURS card `estimatedValueZar` and `type` props:
```tsx
// OLD
<TradeSummaryCard
  role="yours"
  title={listing.userId === currentUserId ? listing.title : "Your items"}
  estimatedValueZar={yourValue > 0 ? yourValue : null}
  type={listing.userId === currentUserId ? (listing.type ?? undefined) : undefined}
/>

// NEW
<TradeSummaryCard
  role="yours"
  title={listing.userId === currentUserId ? listing.title : "Your items"}
  estimatedValueZar={
    listing.userId === currentUserId
      ? (listing.estimatedValueZar ?? null)
      : (yourValue > 0 ? yourValue : null)
  }
  type={listing.userId === currentUserId ? (listing.type ?? undefined) : undefined}
/>
```

Replace the THEIRS card `estimatedValueZar` and `type` props:
```tsx
// OLD
<TradeSummaryCard

/>

// NEW
<TradeSummaryCard
  role="theirs"
  title={listing.userId !== currentUserId ? listing.title : "Their items"}
  estimatedValueZar={
    listing.userId !== currentUserId
      ? (listing.estimatedValueZar ?? null)
      : (theirValue > 0 ? theirValue : null)
  }
  type={listing.userId !== currentUserId ? (listing.type ?? undefined) : undefined}
/>
```

**No other changes.** The loader already selects all listing columns (`db.select().from(listings)...`) so `listing.estimatedValueZar` and `listing.type` are already in scope — no loader changes required.
