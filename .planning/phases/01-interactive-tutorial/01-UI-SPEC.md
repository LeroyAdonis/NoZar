| Secondary (30%) | `#0F172A` | Slide card surface (if used), feature list item backgrounds (`bg-[#0F172A]`) |

Accent reserved for:
1. Active progress dot (current slide indicator)
2. Primary Next → / CTA button background
3. Emoji illustration container border ring (`border-emerald-500/30`)

Accent is **NOT** used on: body text, inactive dots, Skip link, Back gesture areas.

Supporting surfaces:
- Overlay backdrop: `bg-[#030712]/95 backdrop-blur-xl` — matches existing `WelcomeOverlay` exactly
- Inactive dots: `bg-white/20` (idle), `bg-white/40` (hover)
- Skip button text: `text-slate-500 hover:text-slate-300`

## Animation Contract

> All animations use Tailwind utilities only. No Framer Motion, no Lottie.
> Max duration: 250ms. Animations are decorative — must not block slide interaction.

### Overlay Enter (once, when TutorialOverlay mounts)

```
animate-in fade-in duration-300 ease-out
```
Applied to the outer `fixed inset-0` wrapper.

---

### Per-Slide Content Transition (on every slide advance / back)

The content wrapper (`max-w-sm` div) uses a two-phase CSS state swap controlled by a `transitioning` boolean in React state:

| Phase | Classes |
|-------|---------|
| Idle / visible | `opacity-100 translate-y-0 transition-all duration-200 ease-out` |
| Exiting (set first) | `opacity-0 -translate-y-2 transition-all duration-150 ease-in` |
| Entering (set after 150ms timeout) | `opacity-0 translate-y-3 transition-all duration-200 ease-out` |
| Back to idle | `opacity-100 translate-y-0 transition-all duration-200 ease-out` |

Implementation pattern:
```tsx
// On advance: set exiting → setTimeout(150ms) → setSlide(next) → set entering → rAF → set idle
```

---

### Emoji Illustration (per slide, on enter)

```
animate-in zoom-in-95 duration-200 ease-out
```
Applied to the emoji `<span>` — leads the content by feeling snappier.

Re-key the emoji element with `key={currentSlide}` to retrigger `animate-in` on each slide change.

---

### Progress Dots (active dot pill)

Active dot width transition (inactive `w-1.5` → active `w-5`):
```
transition-all duration-200 ease-out
```

---

### CTA Button (Primary)

Hover state (existing project pattern from `button.tsx`):
```
hover:bg-emerald-400 hover:shadow-[0_0_20px_rgba(16,185,129,0.4)] transition-all
```

Active/press:
```
active:scale-95 transition-transform duration-75
```

---

### Replay Link (profile.tsx)

No animation — plain `hover:text-emerald-300 transition-colors` consistent with adjacent "Upgrade →" and "Add & verify →" links in the Account tab.

## Component Breakdown

### New Component

#### `app/components/ui/tutorial-overlay.tsx`

| Attribute | Value |
|-----------|-------|
| Export name | `TutorialOverlay` |
| Props | `onDismiss: () => void; onNavigate: (to: string) => void` |
| Internal state | `currentSlide: number` (0–5), `transitioning: boolean` |
| Keyboard | Escape → dismiss (marks seen); ArrowRight / Space → advance; ArrowLeft → back |
| Click-anywhere | `onClick` on the outer backdrop div advances the slide (not dismiss — D-02) |
| Accessibility | `role="dialog" aria-modal="true" aria-label="NoZar tutorial"` on outer wrapper |
| localStorage | Writes `nozar_tutorial_seen = "1"` via `onDismiss` callback |

**DOM structure:**

```
<div fixed inset-0 z-[200] bg-[#030712]/95 backdrop-blur-xl  ← backdrop + click-advance
  role="dialog" aria-modal aria-label="NoZar tutorial"
  onClick={handleBackdropClick}>

  <div max-w-sm w-full mx-auto flex flex-col items-center text-center px-6 py-10>

    <!-- Skip button: absolute top-6 right-6 -->
    <button "Skip" text-[10px] font-mono uppercase tracking-widest text-slate-500 hover:text-slate-300 p-2 absolute top-6 right-6 />

    <!-- Emoji illustration -->
    <span key={currentSlide} text-6xl mb-6 animate-in zoom-in-95 duration-200 />

    <!-- Slide content wrapper (transition target) -->
    <div [transition classes] space-y-4>
      <h2 text-2xl sm:text-3xl font-black uppercase tracking-tighter text-white />
      <p text-sm text-slate-400 leading-relaxed max-w-xs />
    </div>

    <!-- Progress dots -->
    <div flex items-center gap-2 mt-8 mb-6 role="tablist" aria-label="Tutorial progress">
      {slides.map((_, i) =>
        <button key={i}
          role="tab"
          aria-selected={i === currentSlide}
          aria-label={`Slide ${i + 1}`}
          onClick={() => goToSlide(i)}
          className={i === currentSlide
            ? "w-5 h-1.5 rounded-full bg-emerald-500 transition-all duration-200"
            : "w-1.5 h-1.5 rounded-full bg-white/20 hover:bg-white/40 transition-all duration-200"
          }
        />
      )}
    </div>

    <!-- Primary action button -->
    <button w-full py-4 rounded-xl bg-emerald-500 text-[#030712] font-black uppercase tracking-widest text-sm
      hover:bg-emerald-400 hover:shadow-[0_0_20px_rgba(16,185,129,0.4)]
      active:scale-95 transition-all
      onClick={handlePrimary}
    >
      {isLastSlide ? "List Your First Item →" : "Next →"}
    </button>

  </div>
</div>
```
