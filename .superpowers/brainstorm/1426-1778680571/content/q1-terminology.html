Which direction should we go?

A

Full plain language

Replace all jargon with everyday words. Home, Map, Chats, Profile. "Items nearby" not "Nearby Assets". Drop the code-style headers entirely.

B

Keep brand terms, add plain subtitles

Keep "Ping", "Asset" etc. as NoZar brand language, but always pair them with a plain explanation underneath. "Pings — your swap conversations".

C

Phase out jargon gradually

Nav labels go plain immediately (Home, Map, Chats, Profile). Keep "Ping" inside the chat context where it makes sense as a verb. Drop "Node" and "Asset" everywhere.
