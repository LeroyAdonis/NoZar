Key changes summary

Nudge strip

Shows only when the user has zero listings. Disappears once they list their first item. Not a banner — just a quiet single-line strip.

Header copy

// Local Index + "Nearby Assets" → "Near you in [city]" + "Swaps available". Location-aware and human.

Card copy

"Seeking:" → "Looking to swap for:". "~R12,000" → "Worth ~R12,000". "2.3km" → "2.3km away". Every field reads as a sentence fragment, not a database column.

"You have something they want" badge

Replaces the awkward "You Have Match" badge. Same logic, plain English. High-signal — tells the user exactly why this card is highlighted.
