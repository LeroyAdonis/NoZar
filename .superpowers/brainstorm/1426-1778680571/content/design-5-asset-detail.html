Key changes

"Ping" + "Propose Trade" → one button

Two confusing buttons become one clear action: "Offer a swap". No ambiguity about which to tap.

Confirmation sheet explains what happens next

Before the chat opens, users see what they're offering, what they want, and a value comparison. No blind leap into a conversation.

Value gap warning

If estimated values differ significantly, a quiet amber notice appears. Sets expectations before the chat, reducing awkward first messages.

"Seeking:" → "Looking to swap for"

The want field gets its own card with a plain label. Not buried in the description or shown as a raw database field label.
