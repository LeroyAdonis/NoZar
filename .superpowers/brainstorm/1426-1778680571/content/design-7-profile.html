Key changes

Two tabs replace one long scroll

"My listings" and "Account" — each has one clear job. Finding your listings no longer means scrolling past avatar controls and stats.

"Archive" → "Hide"

"Archive" is a technical term. "Hide" is what it actually does — removes the listing from public view without deleting it.

Stats in plain English

"Total Trades" / "Completed" / "Avg Rating" → "Swaps started" / "Completed" / "Your rating". Same data, words a first-timer understands.

Verification grouped in one place

Email and phone verification sit together in one "Verification" card, not scattered across the page. Adding a phone number is a single clear action.
