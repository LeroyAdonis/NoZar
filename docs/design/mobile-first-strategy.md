# Mobile-First Design Strategy

## Strategy
- **Base Layout:** Mobile-first by default in Tailwind.
- **Touch Targets:** Minimum 48px height for all interactive elements.
- **Navigation:** Bottom-heavy navigation for mobile accessibility.
- **Scaling:** Use `md:` and `lg:` prefixes for desktop-specific layout adjustments.
- **Forms:** Input fields should be full-width on mobile with clear error feedback.
