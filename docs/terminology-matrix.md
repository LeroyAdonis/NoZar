# NoZar Barter PWA — Terminology Mapping Guide

> **Purpose:** Eliminate Web3/crypto jargon and replace with everyday South African language.
> This document is the single source of truth for all user-facing terminology.

---

## Core Term Mappings

| Technical Term | Replace With | Notes |
|----------------|--------------|-------|
| Node | **Member** | Default choice for people |
| Node | **Trader** | Use for active barter participants |
| Protocol | **Safety Rules** | When explaining how trades work |
| Protocol | **How It Works** | For onboarding/step explanations |
| Exchange | **Trade** | General term |
| Exchange | **Swap** | When items exchange hands directly |
| Bypass inflation | **Keep your Rands in your pocket** | SA-specific value prop |
| Assets / Inventory | **My Stuff** | Casual, everyday |
| Assets / Inventory | **Items I Have** | Slightly more formal |
| Bids / Proposals | **Offers** | Universal trading term |

## Barter & Trading Terms

| Technical Term | Replace With | Notes |
|----------------|--------------|-------|
| Listing | **Item** or **Thing** | What you're offering |
| Valuation | **What it's worth** | Simple value assessment |
| Smart contract | **Trade Agreement** | Binding exchange promise |
| Ledger | **Trade History** | Record of past swaps |
| Wallet | **My Profile** or **My Account** | User's identity & balance |
| Token | **Rands** or **Credits** | Stick to real SA currency |
| Minting | **Listing** or **Adding** | Creating a new item |
| Yield | **Extra Rands** or **Earnings** | Benefits from using platform |
| Staking | **Saving** or **Putting aside** | Locking value for benefits |
| Governance | **Voting** or **Having a say** | Community decision-making |
| Decentralised | **Shared** or **Community-run** | No single company owns it |
| Blockchain | *(Avoid entirely)* | Say "our system" instead |

## SA Marketplace Style Guide

### Tone Principles

| Principle | Do | Don't |
|-----------|-----|-------|
| **Friendly** | "How can we help you today?" | "Submit a support ticket" |
| **Plain** | "Your stuff" | "Your inventory assets" |
| **Trustworthy** | "Your Rands are safe" | "100% guaranteed returns" |
| **Local** | "Rands", "Joburg", "Mzansi" | "$", "USD", "tokens" |

### Voice Guidelines

- Speak like a trusted neighbour, not a tech startup
- Use **Rands** not "tokens" or "coins"
- Say **"Trade"** not "exchange on protocol"
- Say **"Item"** or **"Thing"** not "asset" or "NFT"
- Say **"Member"** or **"Trader"** not "node" or "validator"

### What to Avoid

```
NEVER use:                USE instead:
─────────────────────────────────────────────
Web3                      "our app" / "NoZar"
Blockchain                "our system"
Smart contract            "trade agreement"
Mint / Minting            "add" / "list"
Token / Coin              "Rands" / "credits"
Decentralised             "community-run"
Yield                     "extra Rands"
Stake / Staking           "save" / "put aside"
Protocol                  "safety rules" / "how it works"
Nodes                     "members" / "traders"
Exchange                  "trade" / "swap"
Assets / Inventory        "my stuff" / "items I have"
Bids / Proposals          "offers"
```

## Implementation Notes

- **Consistency is key** — if you say "trade" in one place, don't switch to "exchange" elsewhere
- **Test with real users** — if "Offer" feels off in testing, try "Deal" or "Swap Proposal"
- **SA slang encouraged** — "sharp", " lekker", "mooi" are welcome in casual copy
- **Numbers in Rands** — always show values in ZAR (R100, not $5.50)
